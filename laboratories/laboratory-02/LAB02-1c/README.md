# Project 1c: Green LED (PWM)

## Description
Objective of this project is to switch on an LED with a frequency of 1 Hz at 50% duty cycle using a PWM signal generated by the timer.

## Steps
1. Create a new project in STM32CubeIDE for the F401RE Nucleo board.
2. In the IOC file, configure the "Green LED" pin (PA5) as an alternate function for TIM2 channel 1 (TIM2_CH1).
3. Also, in the IOC file, in the "TIM2" tab, select "PWM Generation CH1" for Channel 1 and then in the "Parameter settings" tab, set the Prescaler to 8399 the Counter Period to 9999, and the pulse to 4999. This will generate a PWM signal with a frequency of 1 Hz and a duty cycle of 50% as described in the following formula:
$$
f_{PWM} = \frac{f_{TIM}}{(Prescaler + 1) * (Period + 1)} = \frac{84 MHz}{(8399 + 1) * (9999 + 1)} = 1 Hz
$$
$$
Duty \ Cycle = \frac{Pulse + 1}{Period + 1} = \frac{4999 + 1}{9999 + 1} = 50\% 
$$
4. Generate the code and open the main.c file.
5. Inside the main function, start the PWM signal by calling the HAL_TIM_PWM_Start() function with the TIM2 handle and the channel number (TIM_CHANNEL_1) as arguments.

    ```c
    // Start the PWM signal on the LED channel
    HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);
    ```

**Note**: *Ensure that the timer clock is enabled and its frequency is set correctly (84 MHz) in the "Clock Configuration" tab of the IOC file to achieve the desired PWM frequency. The TIM2 clock is derived from the APB1 clock.*
